# StackConsole V2

Multi-process microservice engine and interactive local service terminal dashboard.

## Install

Download the latest installer from [Releases](https://github.com/tionic929/stackconsolev2/releases).

## Usage

1. Create a project
2. Add commands (PHP artisan, Vite, Node, etc.)
3. Launch all — monitor logs, status, and ports
4. Use the terminal prompt for ad-hoc commands

## Requirements

- Windows x64
- Python 3.x (must be on PATH)
